# AutoTAMP: Autoregressive Task and Motion Planning with LLMs as Translators and Checkers

Reviewed 2026-09-22 · fulltext_reviewed · candidate · human review pending.

## Neural–symbolic interface

GPT-3/GPT-4 translate instructions and check semantic alignment.

STL formulas, rule-based syntax checks and a formal task-and-motion planner.

Planner trajectories and syntax feedback guide repeated LLM translation; STL constrains joint task/motion synthesis.

## Evidence and limitations

Evaluates language-to-STL planning in single/multi-agent 2D tasks. A supplemental 3D drone simulation is described; physical demonstrations use differential-drive robots.

The drone demonstration omits semantic checking. Ground-robot hardware and 2D benchmark scores must not be counted as UAV flight evidence; known geometry and high planning latency limit transfer.

## Classification

Planner trajectories and syntax feedback guide repeated LLM translation; STL constrains joint task/motion synthesis.

Direct UAV simulation is present, but the fully evaluated translator/checker pipeline is primarily general robotics; retain as a candidate with limited UAV evidence.
