# Verified Compositions of Neural Network Controllers for Temporal Logic Control Objectives

Reviewed 2026-09-22 · fulltext_reviewed · included · human review pending.

## Neural–symbolic interface

Feedforward neural controllers trained from MPC-generated state/action examples.

Co-safe LTL, deterministic finite automata and reachable-set verification.

Automaton search accepts neural-controller sequences only when their reachable sets satisfy each reach-avoid transition.

## Evidence and limitations

Constructs verified controller compositions for aerial-vehicle navigation; numerical UAV examples include successful and rejected compositions.

Guarantees are conditional on the dynamics, initial set and sound reachability bounds. Conservative reachability and restricted search can miss feasible compositions. Numerical studies do not establish real-flight robustness.
