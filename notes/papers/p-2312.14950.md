## Neural–symbolic interface

GPT-4 generates plans and answers runtime queries; YOLOv8 provides scene descriptions.

MiniSpec programs with explicit conditionals, bounded loops, skill calls and exception handling.

Neural outputs become executable programs; the interpreter invokes skills and requests replanning using updated observations.

## Evidence and limitations

Indoor Tello experiments evaluate 11 tasks with 10 repetitions each. MiniSpec and streaming interpretation reduce command-to-first-action delay in the reported setup.

Program restrictions are not a collision-safety proof. Task 9 succeeds in 7/10 trials, exposing geometric reasoning failures. Results depend on an edge server, remote LLM and a small indoor task set.
