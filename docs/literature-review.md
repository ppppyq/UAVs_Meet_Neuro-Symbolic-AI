# 文献检索与综述记录 · 2026-09-22

本轮按“神经符号 AI 基础＋五个研究方向”开展有限范围的文献扩展与证据核查。综述正文已分别写入[中文 README](../README.zh-CN.md)和[英文 README](../README.md)，网站对应的六个独立页面采用相同综述内容。

## 本轮范围与方法

检索使用 UAV/drone 与 neuro-symbolic、probabilistic logic、temporal logic、scene graph、planning、safety、multi-UAV 等主题组合，随后对相关论文作标题精确检索、原始来源核对与有限引文追踪。实际查询和筛选理由保存在[检索日志](../data/search-log.json)。这是一次有界检索，未进行多个学术数据库的穷尽检索、双人独立筛选或系统综述流程；不报告无法复核的总命中数。

元数据优先核对 arXiv、官方会议/期刊页面和出版社提交的 DOI 记录。技术判断注明版本与章节或页码，区分全文、选段和摘要证据。全文审阅指本轮检查了主体方法和实验内容，不等于复现实验、审计代码或完成人工复核。数据中 `human_reviewed` 均保持为 false。

本轮新增 7 条论文记录与 2 项基础资源。当前共有 17 条论文记录，对应 16 项未撤回且去重的研究；其中 6 篇核心方法、6 篇候选记录，另有筛选背景与排除记录。9 条记录具有全文审阅标记；基础资源单独统计为 10 项，不加进 UAV 核心方法数。核心纳入是本项目的证据与范围判断，不表示独立确认论文结论。

## 获取与版权边界

13 份公开可获取的作者存档 PDF 仅保存在工作区本地的 `reference-pdf`，按六个板块归档。下载完成不等于阅读全文；本地清单记录来源和文件哈希。需要登录获取的文献没有绕过访问限制。

仓库与网页只提供原始论文/出版页面链接和原创综述，不托管论文 PDF 或复用论文图表。PDF 目录和 PDF 文件已设置为 Git 忽略项；不因本地获取而假定具有再分发许可。
